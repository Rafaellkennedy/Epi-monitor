# Notas de instalação:

# 1) GPU NVIDIA (recomendado para produção com muitas câmeras):
#    Instale o PyTorch com suporte CUDA ANTES deste requirements.txt,
#    seguindo as instruções em https://pytorch.org/get-started/locally/
#    Exemplo (CUDA 12.1):
#    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# 2) FFmpeg deve estar instalado no sistema operacional (não é pacote pip)
#    e disponível no PATH, pois o OpenCV usa o backend FFmpeg para RTSP.
#    Windows: baixar de https://ffmpeg.org/download.html e adicionar ao PATH.
#
# 3) PostgreSQL deve estar instalado e em execução, com um banco de dados
#    criado (ex.: CREATE DATABASE epi_monitor;) antes do primeiro start.
